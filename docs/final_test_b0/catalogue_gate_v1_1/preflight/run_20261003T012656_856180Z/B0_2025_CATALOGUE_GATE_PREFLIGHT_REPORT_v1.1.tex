\section*{评价指标与诊断}
原 primary metrics 全部保持：global core/occurrence/quantile loss、Brier、AUROC、Average Precision、conditional mean 与 per-tau pinball、32 tau coverage、coverage error、crossing/nonfinite/support violation counts。按全体有效像元累积分子与分母，不平均 batch loss；同分概率采用精确分组，未定义指标为 null 并说明原因。

32 个 $\tau_i=(i-0.5)/32$；rainy 判断先在 float32 用 $R>0.1$ 比较，再提升到 FP64。monthly、spatial、reliability、case、雨强描述区间、quantile groups 和 DIAGNOSTIC\_PROXY 原样继承 2024 review。reliability 使用冻结 0.1 间隔 bins，最后箱含 1；三类 case 各 top10，固定 scene 顺序与 row-major 像元次序处理并列。

雨强区间为 (0.1,1]、(1,5]、(5,10]、(10,20]、(20,30]、(30,50]、(50,$\infty$)。10/20/30/50 exceedance 仅为描述诊断。POD/FAR/CSI 继续 THRESHOLD\_NOT\_FROZEN，不选择阈值。
