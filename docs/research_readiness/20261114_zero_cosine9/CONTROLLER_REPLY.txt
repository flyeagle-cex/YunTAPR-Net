## YunTAPR-Net 总控：ZERO\_DOTE 单Seed科学判据收敛

**我建议批准准备方向，但不设置没有证据支撑的最小效应数值门槛。本轮只判断：在COSINE9条件下，真实DOTE数值输入是否带来可观察的开发集增量。**

这是一项主创新机制筛查，不是DEM主创新的最终验收。

### 一、冻结比较对象

- **REAL：** 已完成的B7/E0/COSINE9，Seed 2029。
- **ZERO：** B7/E0/COSINE9，Seed 2029，仅将8个DOTE数值通道置零。
- 保留真实mask、完整初始权重、数据顺序、4320次更新和E9评价。
- 使用同一2024 Development人口及未加权32节点评分。

定义所有差异为：

\[
\Delta=M_{\mathrm{REAL}}-M_{\mathrm{ZERO}}
\]

负值表示REAL的误差更小；对AP、AUROC等越大越好的指标，正值表示REAL更好。

### 二、最小评价判据

| 指标 | 希望观察的方向 | 科学作用 |
|--------|--------|--------|
| **主指标：全体有雨log Pinball** | Δ \< 0 | 判断DOTE数值是否改善总体条件雨强分布 |
| 强雨R>20 log Pinball | Δ \< 0 | 判断强雨子群是否获得增量 |
| 强雨物理Pinball/20 | Δ ≤ 0 | 防止仅在log空间受益 |
| 弱雨0.1–1 log Pinball | Δ ≤ 0 | 检查是否增加已有弱雨代价 |
| 发生Brier | Δ ≤ 0 | 概率质量保护 |
| 发生AP、AUROC | Δ ≥ 0 | 发生排序能力保护 |

强雨只有717个参考像元时次，并非717个独立天气事件。因此强雨评分只作为重要的机制相关诊断，不能单独证明泛化。

所有指标同时报告REAL、ZERO、绝对差和相对变化；保留六组评价来源及已有雨强层摘要。不增加新的模型输出或阈值。

### 三、不设置人为最小效应界值

当前没有充分依据规定DOTE至少改善1%、3%或5%才算有效。

因此，我建议冻结以下解释规则，而非人为设定科学PASS线：

| 结果模式 | 可作出的判断 |
|--------|--------|
| 总体与强雨均改善，保护指标无退化 | **方向一致的开发性正信号** |
| 部分改善、部分退化 | **混合结果，必须保留权衡** |
| 总体和强雨均无改善 | **本次未观察到DOTE明确增量** |
| 差异仅为浮点舍入量级 | **数值不可区分** |

即使第一种情况成立，也只能记作 `DEVELOPMENT_SIGNAL`，**不能升级为科学PASS或Stage 4完成**。

原有的数值核验容差不能充当科学意义上的最小效应界值。应保存完整精度的有符号差异。

### 四、高海拔、W、M分层是否必须？

**本次最低单模型筛查不强制新增。**

理由是：本轮首先检验DOTE数值输入是否产生可观察增量；现有六组评分及雨强分层已经足以完成这个有限任务。

但必须明确，这意味着本轮**不能验收V1.3要求的地形机制**。

后续若要声称DOTE在高海拔、强迎风和高水汽条件下更有效，就必须使用预先冻结的定义开展分层分析：

- DEM：数字高程模型，定义高海拔条件。
- W：Windward（迎风地形作用指标），定义强迎风条件。
- M：Moisture（水汽条件指标），定义高水汽条件。

这些分层的计算口径、阈值、样本数及评价指标必须先在训练期数据或既有物理定义上冻结，不能看到Development结果后选择最有利的分界。**本轮不需要为此扩大工程范围。**

### 五、归因限制及失败后的路线

本轮必须保留两个限制：

第一，ZERO仍保留128个接收零输入、没有损失梯度的权重。因此，即使REAL更好，也只能有限支持**显式DOTE数值输入的效用**，不能证明完全匹配有效训练容量下的严格因果效应，更不能证明全部DEM模块的贡献。

第二，历史REAL/COSINE9执行代码与本次ZERO技术代码不同。必须在准备包中列明非DOTE数值路径、调度、初始化、数据顺序及运行环境的继承证据。如果身份存在无法消除的差异，比较应标为条件性，而不能伪称完全严格配对；不因此擅自重训REAL。

**如果本轮结果失败：** 停止围绕DOTE数值输入继续做无界调参，转而优先研究已有V4确认的R>20点雨强零检出问题及监督目标、点估计表达问题。不能自动启动E1、DTFM或多尺度实验。

**如果结果出现一致正信号：** 保留DOTE作为待验证候选；下一步才考虑地形条件分层、多个Seed及独立观测验证，仍由研究者另行决定。

### 六、总控最终建议

**建议研究者一次性冻结的方案**

**主问题：** COSINE9条件下真实DOTE数值输入是否改善条件降水反演？

**主指标：** 全体有雨未加权32节点log Pinball。

**关键诊断：** R>20 log及物理Pinball。

**保护：** 弱雨log、发生Brier/AP/AUROC。

**效应界值：** 不预设没有科学依据的最小改善百分比，保留完整有符号差异。

**结果级别：** 仅开发性证据，不作科学PASS。

**新增高海拔/W/M分层：** 本包不要求，Stage 4机制验收前必须补足。

我的科学方案意见至此收敛。**这不是训练启动批准。** Codex可按上述范围完成准确提案，Harness仍负责独立审核，研究者保留代码版本、执行预算、时间与新输出目录的最终批准权。
