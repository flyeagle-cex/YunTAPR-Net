[依赖身份检查](metadata_dependency_identity.json)表明九模型的 `data.py` 存在两个文件版本，不能宣称整个文件相同；其中人口加载器 `PopulationPlan` 的AST（抽象语法树）一致，坐标与契约加载依赖一致。检查没有改变人口、统计量或模型。
