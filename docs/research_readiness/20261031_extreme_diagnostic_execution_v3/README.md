## 配额遗漏与完整元数据核查

冻结统计SQLite（轻量级关系数据库）档案33,804,288字节，在原人口加载器中先散列校验、再作只读连接。两次档案预留即67,608,576字节，已超过原单任务64 MiB上限67,108,864字节，尚未计其他元数据。先前准备未完整核算此路径。

停止后，独立的只读元数据准入检查禁止所有科学载荷，完整走冻结人口与坐标路径，额外覆盖六次坐标网格构建与两次静态生产元数据读取。[结果](../20261031_extreme_diagnostic_execution_v2/launch/metadata_only_preflight.json)为119,168,690档案参考字节／80打开，训练959、开发963身份通过，科学载荷打开0。此准备读取量单独披露，不是模型推理重试。

九模型人口加载器的AST（抽象语法树）一致；整体 `data.py` 有两个版本，不宣称整个文件相同，详见[依赖核查](../20261031_extreme_diagnostic_execution_v2/launch/metadata_dependency_identity.json)。真实模型端到端一致性仍为 NOT_VERIFIED（尚未充分验证）。
