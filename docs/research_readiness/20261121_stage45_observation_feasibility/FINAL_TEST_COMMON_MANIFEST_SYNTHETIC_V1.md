# 独立年份共同场景清单的合成验证

2026-11-22。增加仅处理虚构 2001 年内存元数据的共同场景清单。两臂及以上均通过时序和身份一致性校验后，取各臂合格场景交集。清单逐臂记录缺失和范围外样本，统计共同场景按数据类型去重后的来源数，并生成稳定的 SHA-256。相同样本 ID 的来源不一致，或同一靶窗被赋予两个样本 ID 时立即报错。[实现](../../../src/yuntapr/experimental/research_readiness/final_test_manifest.py) · [测试](../../../tests/research_readiness/test_final_test_manifest.py)

| 元数据 | 合成验证内容 |
|---|---|
| 时间锚点 | A 为 00、06、12 或 18 UTC。IMERG 靶窗为 [T, A)，其中 T 比 A 早 30 分钟。 |
| 卫星 | 六个七通道时隙依次为 A 前 60 至 10 分钟，步长 10 分钟。CF 观测结束单调递增且不晚于 A。每帧绑定来源和共同原生网格身份。 |
| GFS | main 和 thermo 绑定各自来源与共同原生网格，初始化时刻比 A 早 6 小时，有效时刻 A，时效 f006，冻结 13 变量。 |
| IMERG | V07 Final 半小时平均雨强，单位 mm/h。日期与半小时索引由 T 决定。午夜 A 对应前一日 23:30 和索引 47。 |
| 评价空间 | 100×100 目标场，每场景 3,430 个监督点。SP04、监督掩膜、静态地形和 Train 归一化分别绑定摘要。 |

验证了按 T 或 A 限定半开范围时，3–9 月及 3–10 月两种合成参数在月初午夜产生不同结果。也验证了双臂缺景、同日 IMERG 去重、重排后摘要一致、未来卫星扫描、GFS 配对错误、冻结身份冲突与嵌套真实年份拒绝。既有三项注册目录和载荷拒绝测试，以及新增五项共同清单测试，共八项通过。

正式 2025 评价范围、日期锚点和实测共同场景覆盖待冻结或确认。实际推理适配未实现。合成验证未打开载荷，也未测实测 CF 坐标、历年文件可用性或真实有效像元覆盖。2025 保持封存。[IMERG 参考评价协议](IMERG_REFERENCE_EVENT_PROTOCOL_V1.md)
