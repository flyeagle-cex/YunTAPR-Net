## 已冻结的参考配对

- 使用 IMERG_V07_Final 半小时平均雨强，单位 mm/h。沿用冻结 SP04 约 0.1° 格点及云南监督掩膜。每个目标窗口 [T, T+30 min) 对应分析时刻 A=T+30 min，时标记录为 UTC。按目标窗及网格身份配对，使用两臂共同有效样本。强雨真值严格 >20 mm/h，对应完整半小时累计 >10 mm。
- IMERG 的 Final Run 是处理流，V07 是算法版本，2025 Final Test 是划分。IMERG 同时是训练标签来源，当前评价解释为对该参考产品的雨强表现与一致性。模型和方案冻结后，2025 可用于时间留出检验。
- 2024 Dev 已确认 963 个配对场景、3,303,090 个有效像元时、717 个强雨像元时，分布在 207 个含强雨窗口。大多数相邻场景间隔 6 小时。保留场景、窗口、像元时和参考过程各自的统计单位。2024 已参与开发选择，重新分组仍用于开发描述。

## 事件评价草案

| 项目 | 准备口径 |
|---|---|
| 参考侧过程 | 任何新增读取须绑定明确预算。若有获批的连续 IMERG，用参考雨强、时间坐标及有效掩膜构造候选过程。采用半小时相邻槽连接、缺测断开及截断标记方法。参考过程的划分依据参考资料和可用性。 |
| 待冻结参数 | 过程识别的强度条件、4/8 邻域、跨时槽移动半径、最小面积和持续时间、边界纳入及长过程分离规则尚无适用冻结值。在正式评价前绑定唯一规则，登记版本及依据。 |
| 身份及覆盖 | 目录身份绑定参考版本、网格、时间覆盖、质量掩膜及规则版本。记录参考过程起止及截断标记，映射共同模型窗口，报告可匹配与可评价过程数、高海拔覆盖和有效窗口比例。 |
| 稀疏覆盖 | 仅有现有稀疏窗口时，报告共同窗口及预设时间块表现，时间块推断须另证依赖条件。部分覆盖的过程限于匹配时窗内的检出。完整过程检出需要连续模型覆盖。 |
| 停止条件 | 既有资料无法确认连续参考、共同模型覆盖或参数适用性时，登记缺项并保留窗口级口径。目前事件数未知。 |

## 更新后的五个工作包

1. **IMERG 参考评价准入**。产品与现有配对身份已确认。事件覆盖决定可报告的范围。
2. **冻结评价协议**。以本草案为基础，固定强雨物理幅值、误报、弱雨与发生头保护、同源事件或时块口径。2025 历史方案有 3–9 月与 3–10 月差异，另行绑定版本与执行预算。
3. **单一候选 Dev 验收**。提出可证伪的强雨幅值与误报改进假说，获批后按冻结门槛评价。COSINE9 作匹配参考，保留 A20 和 TAIL20 的失败结果。
4. **多 seed 与地形机制复现**。用同协议 REAL/ZERO 对照核验山区增益、误报和反例。按实际覆盖限定事件结论。
5. **一次性 2025 泛化与实验封口**。冻结候选、比较器、数据版本、指标和预算，按获批范围一次评价。汇总结果、反例与复现材料后开始论文写作。
