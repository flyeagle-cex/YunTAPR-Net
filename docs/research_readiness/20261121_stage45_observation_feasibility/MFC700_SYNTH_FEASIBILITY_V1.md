# 700 hPa 水汽通量辐合的合成可行性

2026-11-22。按网页科研总控选定原生格 700 hPa 水汽通量辐合为唯一待证物理量。球面差分的合成检查通过。真实判别力和第 3 步仍 **NOT_VERIFIED**。

在原生 0.25° 经纬网格上计算 700 hPa 水平水汽通量净入流除以球面单元面积。面通量为面平均比湿乘面法向风速，分解为中心比湿乘风场辐合与余下的水汽平流项。中心与四邻全部有效且地面气压严格大于 70,000 Pa 才计算，外边界留空。结果单位为 s⁻¹，含量以 kg/kg 计。这是单层水平诊断，尚无水汽收支闭合或降水因果证据。

| 合成对照 | 结果 |
|---|---|
| 高湿、均匀东风、无水平汇聚，包含正迎风坡梯度对照 | 辐合 0 |
| 平地且比湿均匀，风速向东西中心汇聚 | 2.40×10⁻⁷ s⁻¹，全部来自风辐合项 |
| 均匀东风，西湿东干 | 1.60×10⁻⁷ s⁻¹，全部来自平流项 |
| 纬向球面度量、南北轴反转、面积积分与边界净流 | 通过，面积积分残差 3.64×10⁻¹² m²/s |
| 混合风场的逐格分解 | 最大残差 7.94×10⁻²² s⁻¹ |
| 地表气压等于 700 hPa 或一个输入缺测 | 两处中心和受影响的四邻均停用 |
