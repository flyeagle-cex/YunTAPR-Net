# B13 平移与尺度配准的合成筛查

2026-11-22。第 3 步保持 **NOT_VERIFIED**。这次检查只问单通道的六帧 B13 亮温能否把物质云团冷却与冷云覆盖增加区分开。真实数据读取、检查点加载和训练更新均为零。[前序纯平移反例](COSINE9_SAVED_TAIL_GRADIENT_PREPARATION.md)

## 机制与检查

在完整有效的 7×7 窗内，对每相邻十分钟的合成帧检查 125 个配准。平移为每轴 −2 至 2 个像元，反向尺度为 0.90、0.95、1.00、1.05、1.10。去均值残差 MSE 不超过 0.25 K² 且双线性插值支撑齐全才计入。取各合格配准的像元降温中位数，再取最小值并减去 0.10 K 合成裕度。五个相邻时段的最小值须超过沿用的 0.75 K/10 min 激活线。任一时段缺有效支撑则停用。

| 六帧合成对照 | 持续降温下界（K/10 min） | 激活 |
|---|---:|---|
| 等温平移加尺度变化，每步的真变换包含在候选中 | −0.82954 | 否 |
| 真实降温 1.50 K/10 min | 0.52442 | 否 |
| 真实降温 2.00 K/10 min | 1.02442 | 是 |
| 冷暖两层温度固定，只增加冷层亚像元覆盖 | 1.02442 | 是 |
| 中间时相缺一个目标窗像元 | 无可用值 | 停用 |

初次运行的 1.50 K/10 min 真降温对照未过线。保留该对照，再增加 2.00 K/10 min 真降温对照及同观测反例，配准、裕度和激活线保持原值。按 10.4 µm 单色普朗克辐射作合成，两层各自温度固定，通过冷层面积变化复现后者六帧的亮温，最大差为 5.68434e-14 K。该反例不依赖配准搜索遗漏。

## 终态

按网页科研总控的合成停止条件封存此 B13 单通道物质冷却门控。合成对照同时显示了漏触发和错误触发。保守下界仍可描述给定配准集合下的表观亮温变化，真实强雨判别与误报率均未测。当前存档缺少同身份的 B13、固定 E9 逐像元预测和真值，且该假说未走到真实诊断准入。九项联合验收规则及 2025 封存状态保持。
