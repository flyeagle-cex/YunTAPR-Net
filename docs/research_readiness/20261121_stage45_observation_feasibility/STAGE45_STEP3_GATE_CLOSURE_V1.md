## 2. 已穷举的干预族（全部未通过九门）

1. **单改发生概率或统一单调校正**：受 p 与条件均值双坐标支配；真强雨条件分位均值最高 14.16 mm/h，小于 20，无法产生 A 命中，只能移动排序。排除，封存。
2. **PHYS20**：九门中 8 项失败，封存。
3. **TAIL20**：强雨物理 Pinball 0.506865→0.504120（改善），但固定 A 真强雨命中仍为 0，q32 非强雨 6,602 大于 5,769，合计 7/9 未通过，封存。
4. **A20 双侧校正**：2/9，真强雨命中 627、非强雨误报 177,098，封存。
5. **A20 覆盖恢复**：2/9，命中 586、误报 128,804，pinball 0.55001，封存。
6. **阈值加权 CRPS 与 q32 惩罚**：仅完成合成约束，真实 Dev 准入证据缺失，封存。
7. **固定 p、q32 与弱雨损失的共享标量族**：真实 Dev 非强雨最早越线 α = 0.11715633006770076，强雨最早越线 α = 0.8040813513052854，负类先行，判 `NEGATIVE_CROSSES_FIRST_CLOSE_SHARED_SCALAR_FAMILY`；Train 全节点线性规划十例中 0 见证、6 排除、4 未决。封存。
8. **保存端点弱雨保恒顶点族**：Dev 717 个强雨中仅 5 个在理论上可达 A > 20（最大 A = 23.676162719726562），其中仅 1 个自身强雨 Pinball 改善（Δ = -0.1299363393282169）；可达非强雨 138 个。共享 α 形式已由第 7 条否决，逐像元门控需要真值或尚未冻结的特征，不能作为可冻结候选取证。
9. **MFC700 原生格水汽通量辐合（唯一指定物理新候选）**：
   - Train 同景同海拔低 q32 匹配诊断：335 对中 MFC700 严格胜出 184 对（54.93%），仅 `DESCRIPTIVE_TRAIN_SIGNAL_ONLY`，不足以证明幅值可行性。
   - 该动作的唯一可执行形式（对激活像元 32 个分位统一加正增量 δ）已单次真实执行：首个真强雨命中开下界 12.165278596842699 mm/h，大于共同上界 0.006296141592692095 mm/h（非强雨固定 A 零误报上界 7.920633287802471 mm/h、q32 上界 0.006296141592692095 mm/h），判 `STOP_NEGATIVE_CEILING`，该动作形式否决。
   - 特征门控的弱雨保恒变体尚未预注册：Train 逐像元预测没有存档，须新固定前向（16,066,485,320 字节 / 4,637 次 / 2,400 秒），且 Dev 可达像元还需特征读取；在本轮已冻结的准入与预算条件下，它不构成一个可冻结的单一候选。
