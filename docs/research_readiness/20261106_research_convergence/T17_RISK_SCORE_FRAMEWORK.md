## 2. A类：结构性P20边界与保守风险偏序

令
a(r)=max({τ_i:v_i≤r}∪{0})，
b(r)=min({τ_i:v_i>r}∪{1})。
对与节点相容的有雨预测CDF，闭界
L=p[1−b(r)]，U=p[1−a(r)]
约束其Pθ20。原子和严格不等号可能使某端点不可取到，故这里是保守闭界，不声称所有闭端点均可达。它不是真实P20置信区间，不能检查一次0/1观测是否“落入概率区间”来证明校准。

对两个像元时次x,y：
L_x>U_y → 所有相容预测概率均满足x风险高于y，记DETERMINATE（可判定）；
区间重叠/接触而无严格分离 → NOT_ORDERED（尚不能确定严格顺序）；
两者均为相同单点区间 → STRUCTURAL_TIE（结构相等）。
这是保守偏序，未判定不等于真实风险相等。不得对未判定对取区间中点后声称得到已识别的总排序。

未来可报告不可比较对比例：在所有无序样本对中，既非L_x>U_y也非L_y>U_x的比例，并单独列结构相等。该比例不需要构造N×N矩阵，可由边界排序和计数实现；本轮不计算。偏序本身没有唯一AP/AUROC或TopK结果，不强行用文件顺序补出“概率排名”。

重要限制：
若v32≤20，全部节点都≤20，完整节点给出的闭界已经是[0,p/64]；更低节点不再收紧这个阈值的界。
若v32>20，只看q32给出的粗界为[p/64,p]，内部节点才可能继续收紧。完整32节点的使用不等于每个像元都获得新增阈值信息。
T12保存的全像元P20上界最大0.19317626953125<0.5；在相同p/节点/相容性口径下，任何合法补全CDF也不能使0.5阈值产生阳性。这是继承边界的数学推论，不是新评价；不排除改变排序或使用其他决策阈值的可能。

## 3. B类：唯一候选CDF补全规则

只提出一个无拟合参数的候选：在物理雨强mm/h域对CDF线性插值，并以最后区间的密度衔接指数尾部。不是在log域插值；选取哪个尺度本身就是额外假设。

置(v0,τ0)=(r0,0)，要求r0<v1<…<v32且所有数值有限。
F_c(r)=0，r≤r0；
当v_j≤r≤v_(j+1)，j=0,…,31：
F_c(r)=τ_j+(τ_(j+1)−τ_j)(r−v_j)/(v_(j+1)−v_j)；
当r>v32：
F_c(r)=1−(1−τ32)exp[−(r−v32)/h]，
h=(1−τ32)(v32−v31)/(τ32−τ31)=(v32−v31)/2，单位mm/h。
P20_c=p[1−F_c(20)]。

适用与边界：
- F_c单调、连续、从0趋于1；尾部在v32处与最后一段的CDF值及密度相接，尾质量为1−τ32；h从节点确定，不拟合。
- r恰等于v_j时取F_c(r)=τ_j；该预测规则假定连续有雨分布，不声称真实标签没有离散或点质量。
- 支持域下方是CDF零平段；内部相邻节点严格递增，所以没有零长度插值区间。若输入出现相同、交叉或因物理反变换产生重复的节点，候选的数学前提不满足：停止该模型的比较，报告INVALID_INPUT，不去重、排序、加噪或丢弃像元改变人口。本规则不把重复节点自行解释为原子；那需要另一协议。
- 指数尾部是“恒定物理域风险率”的额外假设，给出有限尾部矩，但没有证据证明它适合云南强雨。真实分布未识别；不得静默把尾部置0或临时改尾形。
- 整条CDF使用32锚点，单一P20评分实际依赖夹住20的节点，或最高端的q31/q32间隔；不能宣传所有32个自由度都在每个像元发挥作用。
- 允许不同节点形状和p改变评分顺序；这不是对q32的一次统一严格递增变换。是否比q32更好NOT_VERIFIED。

此规则是一个可审查、低复杂度的补全假设，不是推定正确的降水分布或已校准P20。

## 4. C类：唯一纯排序评分

提出无CDF、无标签、无拟合权重的上半分位幅度评分：
S_tail=p·(1/16)Σ_{i=17}^{32} expm1(q_i)，单位mm/h。
它对p及所用物理分位值分别不减，解释为“发生概率加权的条件上半分位幅度代理”。均匀权重与上半段预先定义，不按结果改节点或权重。

它不是P20、完整均值或新的业务雨强点估计；本轮不对它套R_hat>20检出结论。它只是一种可能使上部曲线更稳定地参与排序的启发式摘要，风险关联方向及实际收益都NOT_VERIFIED。

p和q32相同时，改变q17–q31而保持合法顺序可改变S_tail，证明它不是q32的单变量严格单调重标度；这不证明这些变化含有真实强雨信息。p加权本身也可能贡献变化，因此若未来它优于q32，不能直接把全部收益归因于中间节点。

本轮不增加p+q32匹配对照或其他评分候选。当前最小协议能检验“固定评分是否优于q32”，不能单独识别增益来自p、内部形状还是补全规则；若需归因，另行定义受控问题，不能用本轮结果代替。
