# 四项创新主线、阶段缺口与首轮修复

## 研究者已确定的方向

研究对象为云南复杂地形山区的极端降水反演。四项创新方向为复杂地形多元信息协同框架、风场与地形梯度动态地形强迫、多时相大气环境物理约束，以及 U-Net 底层框架与双输出头。

按研究者授权作出的当前工程选择，使用六时相卫星序列和对应分析时刻的 GFS 环境场。卫星时次为分析时刻前60、50、40、30、20、10分钟。GFS 为已冻结 f006 回顾性环境。物理约束当前实现为环境先验条件输入、物理量与单位绑定、地下层掩码及风场和地形梯度表征。硬守恒约束和业务实时资料可用性各自保留待验证状态。

## 本轮已经修复并检查的工程边界

1. 环境字段在插值和标准化前验证字段名、物理量、Pa压力层、单位、网格形状、掩码类型及有效值有限性。该检查已接入 MEE 和动态地形变换。
2. 动态地形入口严格识别 B6 通道顺序、米制梯度单位、网格和掩码。错误压力层、风分量或梯度单位会明确拒绝。
3. 卫星目标时间契约绑定实际解码环境帧的 forecast identity。已有时序规则继续适用。
4. 海拔分组内已经计算的七个雨强箱保留到新输出，以支持后续海拔×强雨的配对检查。历史已保存输出缺失的交叉统计仍是缺口。

27项人工检查通过，其中一项复用3个既有物理DOTE测试。合法输入的原映射、标准化和掩码输出一致。本轮属于工程准备，新增训练更新为0。科学状态为 `NOT_VERIFIED`。

## 最近完成实验补记

V7两臂固定E9评价已完成，强雨节点形状诊断为强雨子集描述证据。COSINE9的七项开发门槛通过，弱雨log损失相对E0退化约7.59%。

REAL/ZERO同COSINE9对照已完成，REAL总体及强雨log损失相对ZERO分别增加约0.0648%和0.3434%，显式地形数值输入的增益仍待建立。
