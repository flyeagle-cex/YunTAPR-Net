# 阈值加权 CRPS 的固定合成对照

结论为 `STOP_BEFORE_REAL_TRAINING`。阈值加权 CRPS 改善了构造强雨的幅值和固定 A 命中。低发生概率的非强雨样本上，q32 反而升高，弱雨 log Pinball 和发生 Brier 同时退化。七项合成方向检查通过四项，当前参数化止于合成阶段。

## 对照设计

基准为 E0，候选为 E0 加一项全有效像元的双头混合分布评分。无雨原子质量 $1-p$，32 个物理分位原子各为 $p/32$。辅助评分中真值 ≤0.1 mm/h 映射为零。作为固定合成设置，辅助项系数为 1，雨强变换为 `(0.25*x+5*softplus((x-20)/5))/20`，其中 20 是强雨阈值，5 mm/h 是平滑尺度。设置在运行前固定于代码提交 `77bdbf8`。

四个训练网格与一个独立种子生成的评价网格各含 288 个有效合成像元，覆盖六类固定输入。使用共享的 1×1 特征层和仓库原双头输出，配对使用同一初态、网格顺序与原 AdamW、梯度裁剪。两臂各 144 步，从冻结 COSINE9 每隔 30 个更新采样一个学习率位置，终点对应第 4,320 个调度位置。发生头采用 CUDA BF16，条件头用 FP32 卷积及 FP64 参数化。该网格没有真实地形或气象特征，合成固定分数验收仍不能代表正式 2024 Dev 九门。

## 结果

| 指标 | E0 | E0 + twCRPS | 候选变化 |
|---|---:|---:|---:|
| 低估强雨组平均 A，mm/h ↑ | 12.7351 | 13.2017 | +0.4666 |
| 低发生概率非强雨组平均 q32，mm/h ↓ | 39.4782 | 40.9081 | +1.4299 |
| 强雨物理 Pinball/20 ↓ | 0.217264 | 0.198889 | −0.018375 |
| 弱雨 log Pinball ↓ | 0.014475 | 0.014861 | +0.000386 |
| 发生 Brier ↓ | 0.018634 | 0.018729 | +0.0000954 |
| 固定 A 命中 / 误报 | 0 / 0 | 12 / 0 | +12 / 0 |
| q32 越线命中 / 误报 | 12 / 72 | 24 / 72 | +12 / 0 |
| 平均 twCRPS ↓ | 0.043937 | 0.043577 | −0.000360 |

发生 AP 和 AUROC 在两臂均为 1，构造任务在这两项上已饱和。低发生概率负例组的两臂平均 $p$ 均为 0.0100098。评分与暴力两两公式的函数值和梯度一致，掩膜排除了无效位置的 NaN。单像元的低 $p$ 负例 q32 梯度方向向下，但量级仅约 $6.02\times10^{-9}$，联合更新后该组 q32 高于 E0。两臂没有触发梯度裁剪。当前证据无法把组间变化归因于共享层、归一化参数化或 AdamW 中的某一项。

合成混合分布反例同样成立。准确的分布在附加评分上胜过把固定 A 从 15 抬到 22.5 的概率膨胀版本。固定 A、q32 护栏及强雨物理幅值仍各需验证。按事先锁定的合成门槛封存本设置。正式训练、真实权重加载及气象载荷读取为零，2025 封存。[机器收据](A20_TWCRPS_SYNTHETIC_RESULTS.json) · [可复现脚本](../../../tools/research_readiness/a20_twcrps_synthetic.py)
