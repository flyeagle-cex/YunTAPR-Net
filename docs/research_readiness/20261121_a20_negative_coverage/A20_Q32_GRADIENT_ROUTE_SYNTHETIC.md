# q32 惩罚的共享层梯度对照

结论为 `STOP_BEFORE_REAL_TRAINING`。切断 q32 惩罚传入共享特征层的梯度后，固定 A 的 12 个合成强雨命中恢复，强雨物理幅值较 E0 改善。弱雨 log Pinball 与发生 Brier 仍未达到护栏，十项合成检查通过八项。

## 控制项

从原 E0 + twCRPS + 直接 q32 惩罚出发，只对 q32 惩罚使用停止梯度的共享特征。惩罚仍更新条件分位头，权重 0.1、有效非强雨掩膜、阈值 20 mm/h 及前向数值保持一致。E0 和 twCRPS 分支照常更新共享特征。配对核对两个基准收据的哈希、CUDA BF16 与 PyTorch、固定合成网格和初始指标，新增一个 144 步合成臂。代码在运行前固定为 `69834c1`。[原直接惩罚对照](A20_Q32_GUARD_SYNTHETIC.md)

在首个合成训练网格，普通分支与停止梯度分支的输出、损失及流入输出头的梯度逐项完全一致。首批局部导数显示，单独按 q32 惩罚梯度走一步，低估强雨的平均 A 会同时受到共享层和输出头路径的下压，单位步长变率分别为 −0.7414 与 −0.9143。两条路径也都直接压低低概率干例的 q32。这是初态局部机制，完整 AdamW 轨迹受 E0、twCRPS 和优化器状态共同影响。

## 终点

| 指标 | E0 | q32 惩罚全梯度 | 切断惩罚到共享层 |
|---|---:|---:|---:|
| 低概率非强雨组平均 q32，mm/h ↓ | 39.4782 | 38.2458 | 39.4527 |
| 低估强雨组平均 A，mm/h ↑ | 12.7351 | 12.6297 | 12.9684 |
| 强雨物理 Pinball/20 ↓ | 0.217264 | 0.220727 | 0.208462 |
| 固定 A 命中 / 误报 | 0 / 0 | 0 / 0 | 12 / 0 |
| q32 越线命中 / 误报 | 12 / 72 | 12 / 72 | 12 / 72 |
| 弱雨 log Pinball ↓ | 0.014475 | 0.014561 | 0.014595 |
| 发生 Brier ↓ | 0.018634 | 0.018730 | 0.018729 |

相对 E0，低概率负例的 q32 仅下降 0.0255 mm/h，略高于合成方向门槛要求的最小降幅 0.02 mm/h，越线误报仍是 72。发生 Brier 与未加直接 q32 惩罚的 twCRPS 在该合成评价上的结果完全相同。AP 和 AUROC 都已饱和。证据支持共享层梯度会影响强雨幅值这一局部机制，并显示仅切断这一路径不足以取得联合达标。
