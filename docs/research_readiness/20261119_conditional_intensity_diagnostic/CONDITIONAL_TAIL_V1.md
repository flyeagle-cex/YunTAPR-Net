## 评价定义

监督人口为冻结的 963 场景和 3,303,090 个有效像元时。实测强雨使用 FP32 严格 `R > 20 mm/h`，分母 717；非强雨分母 3,302,373；弱雨为 FP32 `0.1 < R ≤ 1 mm/h`，分母 246,473。

主指标是在实测强雨上计算 **物理 Pinball/20**。每个像元将 FP64 的 32 个 qlog 用 `expm1` 转回物理雨强。每个节点计算 `rho_tau((R - expm1(qlog))/20)`，其中 `rho_tau(e) = max(tau*e, (tau-1)*e)`，`tau = (k - 0.5)/32`，`k = 1…32`。先对 32 节点取均值，再对 717 个像元时取均值。越低越好。

| 验收项 | 基线 | 候选要求 |
|---|---:|---|
| 强雨物理 Pinball/20 | 0.5068646309 | 严格下降 |
| q32 节点支持的强雨命中 | 160 / 717 | 不降低 |
| q32 节点支持的非强雨标记 | 5,769 / 3,302,373 | 不增加 |
| A 点值强雨命中 | 0 / 717 | 超过 0 才报告检出恢复 |
| A 点值误报 | 0 / 3,302,373 | 不增加，按绝对数比较 |
| 弱雨 log Pinball | 0.0887223116 | 不升高 |
| 发生头 Brier | 0.0923301557 | 不升高 |
| 发生头 AP | 0.6066547556 | 不降低 |
| 发生头 AUROC | 0.8990243639 | 不降低 |

q32 支持固定为 FP64 `qlog32 > log1p(20)`。A 点值固定为 `p × mean(expm1(qlog))`，用 FP32 严格 `A > 20` 分类。发生头评分覆盖全部有效像元时，沿用冻结的 `R > 0.1` 及原 AP/AUROC 排序和并列处理。弱雨使用 32 个节点的 log Pinball 均值。比较使用机器收据中的全精度值。

## 比较入口与结论范围

`conditional_tail_gate.py` 提供 `baseline --receipts-root` 和 `candidate --baseline --candidate`。候选聚合收据必须使用同一协议、人口和身份摘要，覆盖场景顺序、分区、监督 mask 及真值空间对应关系。指标字段与 [基线收据](CONDITIONAL_TAIL_BASELINE.json) 一致。汇总验收要求主指标严格下降，同时其余护栏全部通过。A 点值是否恢复另行报告。

最小合成检查覆盖基线自比失败、主指标下降且护栏不变时通过、增加 1 次误报时失败、错配 mask 时拒绝。当前没有已训练候选；单种子 Dev 门槛通过后，结论最多是此人口上的条件尾部指标改善。节点支持只表示分位点超过阈值。概率校准、地形机制和跨年泛化仍待证据，2025 Final Test 封存。
