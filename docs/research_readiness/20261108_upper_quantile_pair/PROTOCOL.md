# 温和上分位加权配对筛查

状态为 PROPOSED，等待研究者对准确版本和新增预算的一次批准。本记录不授予训练权限。

## 科学问题

E2 已有结果不支持把整个条件分位任务的权重提高到 2 能稳定改善强雨。网页总控本轮建议只提出一个固定候选 UQ_MILD_V1，采用 B7 concat 作为诊断载体。当前选择依据是干预可分离和工程成本，尚无候选间效果比较，也未选择最终模型。

## 唯一干预

沿用原 32 个中点分位水平，tau_k=(k-0.5)/32。固定 w(tau)=2(1+tau)/3，正权重之和为 32，范围为 65/96 至 127/96。每个湿像元的条件 Pinball 按该权重加权并除以权重和。总目标为 (S_occ+S_qr_weighted)/N_valid。

E0 对照保持均匀分位权重。两臂的发生项保持 alpha=0.5、gamma=2，lambda_q=1，32 节点、log1p 空间、网络结构和监督 mask 保持冻结。原 s_qr 及所有科研评价继续使用未加权定义。

两臂均为 B7 / Seed2029，从相同原始工厂初态训练九轮、取固定 E9 LAST。候选必须逐轮匹配新 E0 的初始完整参数 SHA 与九轮样本顺序摘要。历史 E0 的完整运行时指纹不足，本次计划重跑同环境对照，旧 E0 和旧 E2 结果全部保留。

## 预先冻结的筛查判据

强雨使用原有效 mask 下的 R>20 mm/h。要求强雨未加权 log Pinball 与物理雨强 Pinball 同时下降。物理分位值为 expm1(qlog)，使用原分位水平，固定除以 20 mm/h 归一化。

五项保护指标为全部湿像元的原 log Pinball、物理 Pinball、全部有效像元的发生 Brier、发生 AP、发生 AUROC。损失和 Brier 不上升，AP 和 AUROC 不下降。科学退化容限为零，绝对浮点舍入容差固定为 1e-10。强雨改善必须超过该容差。

q32 覆盖率仅作辅助诊断。物理诊断复用每轮原 Dev 前向输出，不增加独立推理遍历。出现非有限物理分位值立即失败，不裁剪或静默剔除。该筛查是单 seed、重复使用 Development 的探索性判断，不形成显著性、最终模型或科学验收结论。
