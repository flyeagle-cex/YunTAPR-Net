## 拟议一次包

1. 一次共享的2023训练标签与掩码统计，959场景；不读取训练气象或执行训练前向。
2. 既有B4/B7/B8、种子2029/2030/2031的九个固定E0/E9模型，每模型恰好一次2024开发人口前向。每模型963场景、3,303,090监督像元时次、有雨407,820。
3. 顺序为共享标签，然后各种子的B7→B8→B4；首个B7提供本包内共享物理分层上下文，B4关联前逐批检查时空键、监督索引与真值一致。监督不因压力层特征无效而删减。
4. 原模型前向和评价器数值路径沿用；旁路只保存已经计算的输出。概率采用FP32（32位浮点）承载原BF16（脑浮点16位）或FP32取值，条件分位数保留FP64（64位浮点）。
5. 主阈值严格大于20 mm/h，次要5/10/50，记录等于20/50的边界。全部A/B/C点估计同时报告。概率使用有限分位数支持的可识别范围，不补零尾部、不拟合新尾部、不按开发技能调阈值。
6. Brier Score（布里尔分数）与AUROC（受试者工作特征曲线下面积）报告可识别范围；AP（平均精确率）保留无法点识别。逐种子差值优先；三种子均值与样本标准差仅为描述。真实雨强分层后的条件覆盖不作为逐层名义校准检验。
7. 七个固定雨强层、四UTC（协调世界时）、三高程组、DOTE（动态地形与热力／水汽强迫表征）方向／压力有效性／水汽分层及强雨交叉层保留。分层成员必须跨模型完全一致；零分母保持未定义。
