3. v2 数学定义
==================================================

保持：

occurrence threshold = 0.1 mm/h

rain occurrence：

p = P(R > 0.1 mm/h)

32 个 conditional quantiles
（条件分位数：在已经发生 R>0.1 mm/h 的条件下预测的降水分布分位点）

tau_i = (i - 0.5) / 32


保持：

z0 = log1p(0.1)


v2 quantile head：

模型输出：

allocation logits:
a_1 ... a_32

以及：

span logit:
s


定义：

w_i = softplus(a_i) + epsilon_w

W = sum_{j=1}^{32} w_j

c_i = sum_{j=1}^{i} w_j / W


因此：

0 < c_1 < c_2 < ... < c_32 = 1


定义总跨度：

S = softplus(s) + epsilon_span


最终：

q_i = z0 + S * c_i


因此：

q_32 = z0 + S


而不是旧版本：

q_32 =
z0 + Σ softplus(a_i)

7. TRAINING PATH DECOUPLING
==================================================

正式 training forward
（训练前向传播：输入通过模型得到用于损失函数计算结果的过程）
不得为了 core loss
（核心损失：正式优化使用的主要目标函数）
强制 materialize：

conditional_quantiles_physical

threshold_censored_mean

input
→ backbone
→ SP04
→ occurrence head
→ v2 quantile raw outputs
→ monotonic qlog
→ log-domain loss
→ backward

core loss =
L_occ + L_qr

保持与既有科学定义一致。


physical conversion：

Q_i = expm1(q_i)

只能在显式调用：

physical inference
（物理推理：输出真实 mm/h 分位数）

diagnostic
（诊断：不参与模型参数更新的分析）

evaluation physical products
（物理评价产品：需要真实物理量的输出）

时执行。
