- 真实 smoke：一个进程，两模型各一次事务成功，2 次真实更新额度封存；未因后续测试或文档构建再运行模型。
- 新防护单元测试：最终 39 通过、0 失败；真实 smoke 前的 37 项全部通过。失败日志及原因见 `FAILURES_AND_BLOCKERS.md` 和 `tests/*.redacted.log`。
- 交付静态检查：首轮 55 项通过，含 125 份继承源码 SHA、精确执行源码快照、更新次数、资源预算、数据收据和脱敏检查；收据见 `tests/delivery_validation.json`。静态校验只读已有报告和公开源码，不访问真实数据或权重。
- LaTeX：两次内置编译均成功；外部导出首次因输出目录参数解析失败，无 PDF 产生，日志保留于本轮私有目录。改为在专用临时目录编译，XeLaTeX 成功输出两页 PDF；关闭自动安装，不安装软件或下载字体。
- 受限环境拒绝 MiKTeX 自身 AppData 日志写入；导出与渲染仍成功，未扩大权限解决该无关日志写入。
- 两页最终 PDF 均已渲染检查，公式、中文、表格、页码和换页无裁切或重叠；当前已打开的历史前向 pilot 文档没有修改。
- 公开新增文件不含原始数组、模型/AdamW payload、凭据或本机绝对路径。私有 checkpoint、完整日志、额度 witness 保留在本地并排除 Git。
- 推送使用正常提交与非强制 push，不覆盖他人工作。最终提交 SHA 由 Git 历史和完成消息给出，不能把 Git commit 当成科研审批。

`final_status.json` 中的 PASS 仅指两次限额真实 smoke 事务成功；外部 watchdog 的完整停止联动依然 NOT_VERIFIED。正式实验、历史恢复、最终测试与业务近实时能力没有因此获得批准或验证。
