\textbf{统计与掩膜。}新增B08/B09/B10/B11/B15/B16仅用最终959个Train场景，六时次共5,754次暴露；每波段计1,444,259,754个有效原生网格像元暴露。B13沿用冻结统计。13个GFS变量均完成Train有效层统计；850/700 hPa有效比例约50.67\%/88.17\%，地下层不参与拟合。T500/RH500在最终目标网格有有效支持，可作为13通道MEE的数据候选；模型适配及科学冻结仍待批准。PWAT正值参考尺度候选已由Train的9,590,000个有效正值场景--像元暴露计算，具体值与完整scaler仅保存在本地。Dev没有拟合贡献。

\textbf{主要科学局限。}相对旧B1，约90\%的描述性强雨场景未被固定f006人口覆盖；总体场景保留约9.17\%。分析时刻仅00/06/12/18 UTC：Train为241/243/238/237，Dev为237/242/240/244；强雨场景分别为34/30/54/41及45/30/78/55。这是场景最大值计数，不能解释为独立暴雨事件数量。两年各一个10月末边界场景已在原申请中排除，本轮没有额外QC排除。历史实际发布时间仍未知，不能推广为业务NRT或2025独立测试结论。
