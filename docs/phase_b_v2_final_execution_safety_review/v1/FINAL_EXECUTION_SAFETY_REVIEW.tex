\section*{4. 科学与批准边界}
训练与共同评价必须区分：
\[
 L_{\rm train}=\frac{S_{\rm occ}(\gamma)+\lambda_q S_q}{N_{\rm valid}},\qquad
 C_{\rm common}=\frac{S_{\rm occ}(2,\mathrm{FP64})+S_q}{N_{\rm valid}},
 \qquad \mathrm{CPB}=\frac{S_q}{N_{\rm rain}}.
\]
\(\tau_i=(i-0.5)/32\)，\(\tau_{32}=0.984375\)。雨标签来自原始float32参考值严格大于0.1 mm/h；\(N_{\rm rain}=0\)时CPB不可估计。E0/E1/E2、paired fresh初始化与科学定义没有修改。

研究者仍须独立决定：科学协议接受范围、M-C探索性报告选择及未定效应/副作用界限；正式源码版本审查与上述修复许可；真实数据消费的独立权限及同字节核验；GPU/CPU commit/磁盘/停止预算；批准事件验真机制和运行范围；首批seed2026六组的独立执行许可。每次真实恢复还须另批具体LAST SHA及原授权祖先。历史B1恢复偏差独立处置，未追认。

现有两个smoke的永久账本、两处witness及3,657个既有src/config/docs文件SHA均不变；原额度仍\code{COMPLETE_SEALED}，预留/进入/返回各2。本轮新增更新为0。以下状态保持：
