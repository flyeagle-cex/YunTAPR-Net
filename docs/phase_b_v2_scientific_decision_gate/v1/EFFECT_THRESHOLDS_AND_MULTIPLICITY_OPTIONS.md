# 效应界限与多重比较：待批选择

推荐 M-C：完整效应与点对点探索区间，不作确认性显著性、功效保证或自动模型采用判决。数值 δ/tolerance 均 NOT_YET_ESTABLISHED；不是填写 0，也不是无限容忍。本轮不以已见 Phase-A 点值设界限。

## 可选的科学意义与副作用标准

令 δ>0 为最小改善、η≥0 为最大可容忍退化。下表只给严格定义及选择依据，不替研究者填写数值。效应方向按各模型、各 seed 原始配对报告；是否要求所有 seed 达标还是等权效应达标须执行前决定，不能看结果后选。

|字段 / 单位|候选定义|依据、成本与限制|
|---|---|---|
|Brier 最小改善；绝对无量纲差|推荐易解释的绝对规则 D_O≤−δ_B；备选相对改善 −D_O/Brier_E0≥δ_rel，E0=0 则 NA；或纯描述不作成功门槛|绝对量可跨相同评价域比较，相对量受基准影响。需用途损失/概率误差价值、独立测量与不确定性证据；没有项目应用代价，δ_B 未建立|
|q32 绝对覆盖误差最小改善；比例或百分点|D_Q≤−δ_Q；备选终点 |C32−tau32|≤η_Q；或纯描述|比例×100 为百分点，不是相对百分比。终点带检查不保证比 E0 改善；需对尾风险、参考误差与事件相关的价值判断，不能拿已见欠覆盖反推 δ|
|Conditional Pinball 容忍；原 log1p 域损失单位|ΔCPB≤η_P；备选 ΔCPB/CPB_E0≤η_rel（基准0则 NA）；严格“不允许点估计恶化”η=0 只能是另选规则|absolute 推荐用于未来可解释界限；对数误差不能写 mm/h。η=0 数值上严格但对噪声敏感，不是统计非劣效证明；纯描述保留全部值但不能宣称可接受|
|AUROC、AP 降低；无量纲差 / 百分点|分别 ΔAUROC≥−η_A，ΔAP≥−η_AP；两者不可共用一个未经说明界限|排序不等于校准；需实际使用价值、样本/参考不确定性。稀有雨情形 AP 尤其受基准雨率影响；不能用区间跨零当“不退化”|
|H-Q 发生 Brier 副作用；无量纲差|ΔBrier(E2−E0)≤η_BQ，并同时报告 AUROC/AP|覆盖改善可能牺牲发生头；需与 H-O 相同应用依据|
|七个真值雨强层 CPB；log1p 域单位|推荐所有既定层完整描述；备选逐层 η_P,b，尤其 >5 mm/h 层各自守卫；再备选最坏层规则 max_b(ΔCPB_b−η_b)≤0|层边界继承，不挑区域或合并有利层。每层 Nr、可用日期块/replicate 要报告；稀疏层不能补0。层界限需参考误差与独立过程证据，尚无依据|
|上尾、q27–q32、span；计数/暴露比例/对数跨度|推荐按旧阈值全量诊断；备选冻结暴露比例增加上限 η_tail,t 与跨度容忍；独立物理核实后再定采用门槛|q32大不等于极端事件；分布变宽可能改善覆盖但恶化 CPB/可信性。10/50/100/500/1000 mm/h 是诊断阈值，非合法裁剪值；不能修补输出后评价|

推荐本阶段选择“描述而无自动采用门槛”，同时保留 δ/η 空字段；这降低无依据签数值的压力，但也明确放弃本阶段科学成功/非劣效/业务采用判决。若研究者需要上述判决，须先提供应用代价、独立参考误差、事件尺度信息和外部证据，单独批准具体界限与联合规则。计算安全仍按非有限、支持、单调性、身份与分母异常立即停止，和科学容忍分开。

## 配对推断与限制

沿[既有统计候选](../../phase_b_v2_ablation_preregistration/v1/STATISTICAL_ANALYSIS_PLAN.md)：2024-03-01 至 10-31，35 个非重叠七日 UTC 块，按 label window_start 归块；2,000 次 Bootstrap，随机种子 2026，同一块重复向量作用所有 18 运行。每次先累计分子/分母再求指标；exact-score AUROC/AP 从合并分数计数重算，不平均周指标。每 seed 先算效应，再等权平均；点对点 2.5/97.5 百分位仅为开发探索区间，不是 seed 随机总体区间。

雨量层无雨、单类、零分母等为 NA；报告有效块/replicate 数及原因，不补0、不重抽到满意。最低有效块数/replicate 比例未建立，未满足明确规则时不出通过判决；计算不了区间则仅给点值与 NA 原因。七日不能保证跨周天气过程独立，季节非平稳、单年及开发集既往选择使泛化推断受限。三 seed×大量像元不是大量独立证据，独立事件数与功效均未建立；本轮不计算 p 值或新增区间。

|候选|附加要求|可宣称范围|
|---|---|---|
|M-C（推荐待签）完整效应、逐项探索区间|冻结四主比较、所有安全项、失败与缺失性；不能选择有利 seed/指标/区间|不作显著性或 FWER 已控制声明；区间覆盖依赖近似抽样假设，不保证 95% 实际覆盖|
|M-A Holm，四主比较候选家族|必须先锁定 H-O/H-Q×B0/B1 的4个零假设、方向、显著性水平、有效 raw p 构造及 seed 汇总；若将副作用/32覆盖纳入正式检验须扩大预定家族。原 percentile CI 不能倒推 raw p|Holm 只校正已有有效检验，不能修复错误独立性、选择偏差或回顾开发集地位|

[Holm 原文](https://www.ime.usp.br/~abe/lista/pdf4R8xPVzCnX.pdf)给出逐步多重检验方法。本项目仍缺可成立的单项 raw p 及抽样依据；配对本身不保证跨块独立，简单交换实验臂也不能自动成为有效随机化检验。[ASA 原则](https://www.amstat.org/asa/files/pdfs/P-ValueStatement.pdf)强调完整报告及不能把统计显著性等同于效应重要性；这里推荐 M-C 是结合本项目证据的判断，非 ASA 对本实验的批准。

M-C 选定仍是待签候选。若仅执行 seed2026，标注 n_seed=1；后续两个 seed 执行范围另批，规则不能随首批效果变化。2024 没有因此变为独立确认集，2025 不解封。
