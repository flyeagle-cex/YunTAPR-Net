## 未来独立获批后的 SHA 选择

|候选|可靠性与成本|风险/适用条件|
|---|---|---|
|I-A 批量完整只读 sweep|对冻结精确引用去重，SHA 对照冻结值；先发现全部身份问题，无模型操作。需读全部未核验字节，真实总大小/I/O耗时尚未建立|扫描结束后文件可能变化，不能仅凭 sweep 给以后任意读取豁免；新只读范围与预算必须批准，禁止搜索替代源|
|I-B 正式读取前严格逐文件校验|每个将使用的文件在 decode/进入 batch 前完成 SHA；任何失败拒绝该文件并停止运行，不跳样。可边读边 hash，额外全量 sweep 成本低|后期才遇坏文件会浪费已训练预算；缓存仅以路径/mtime/size 判断不充分。必须绑定所解码的同一 bytes/不可变版本，避免校验后重开造成 TOCTOU|
|I-C 两者组合（推荐待签）|未来获批先 sweep 使所有引用的身份覆盖完整；正式消费时再绑定已验证不可变对象，或对同一 bytes 严格重验|I/O和存储成本最高，但可早发现且限制校验与消费脱节。若无可审计不可变存储就重验，不能自动降级为 size 检查|

完整 SHA 是当前身份门槛，不能证明业务历史可用时间或科学标签无误。推荐 I-C，资源受限时 I-B 可另行选择，但不能称“正式执行前全部已通过”。同一路径被多次引用可复用经审核的同一不可变内容对象及 SHA；不得在消耗前未经证明地信任缓存。批量扫描即便全通过也不授权模型执行。

未来只读申请应明确：冻结 2023/2024 精确引用、scaler/mask/SP04 的必要身份核对；去重文件数和预估总字节/时限/内存；只读审计与脱敏账本；在任何 resolve/stat/open 前词法年份/根目录拒绝；2025/私有 checkpoint/无关路径禁止；SHA/权限/资源异常停止且不替换；可选受控 OS 追踪以证明未来禁止路径属性访问。此权限不包含模型推理或训练。本轮不创建或启用该申请。
