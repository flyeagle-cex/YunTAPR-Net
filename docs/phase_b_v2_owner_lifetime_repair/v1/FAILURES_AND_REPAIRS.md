## 清理和防止重复消费

任务注册仅针对随机唯一人工名字，拒绝覆盖；无计划触发器、无自动重试。测试正常停止使用 nonce 范围内人工 stop.request；故障注入通过已验证的原生进程句柄终止指定人工 Owner，KILL_ON_JOB_CLOSE 清理其 Worker。没有遍历终止其它 Python 进程。

两个初期失败任务在确认退出、动作路径与登记一致后删除；最终三项任务均由测试框架在退出后注销。只删除人工测试的任务注册，没有删除历史训练账本、会话、launch.once、Checkpoint 或失败证据。

## 原事故与人工失败必须分开

原实际训练没有终止收据。后续只读观察不补写或冒充当时清理成功。关闭 Codex 的人工 Job 复现与用户陈述共同支持宿主寿命耦合的解释；实际事故没有内核调用追踪，仍不应声称唯一归因已经证明。
