\section*{3. 真实 Train-only normalization}
仅 2023 B1 Train 的 10,455 场景参与；六槽共享单一 scaler。计权为 \textbf{scene-slot exposure}：62,730 个槽位暴露，每次含 251,001 native pixels，总权重 15,745,292,730。ddof=0 继承原 B0 样本总体方差定义；2024 / 2025 / raw IMERG 无拟合读取。

每个不同帧只解码一次，按实际出现次数 $m_f$ 累加 int64 packed-code histogram，严格等价于逐场景六槽展开；\textbf{未改成 unique-frame weighting}。真实读取 33,219 个不同 2023 文件；实际像元读数与加权暴露分开记账。
\[
N=\sum_f m_f\,251001,\quad
\mu=\frac{\sum_k h_k x_k}{N},\quad
\sigma=\sqrt{\frac{\sum_k h_k(x_k-\mu)^2}{N}}.
\]
$x_k$ 使用原 reader 的 float32 scale/offset 乘加，保持实际 Kelvin 舍入；mean 与 centered variance 使用 float64。归一化先用 float64 计算，最后转 float32。
\textbf{mean=271.60515414265217 K；std=19.93959597783802 K。}\par
