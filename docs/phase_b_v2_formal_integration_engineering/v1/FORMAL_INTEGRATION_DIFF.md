# 后续正式版本集成差异与阻断

本轮只增加 `experimental/phase_b_v2_formal_integration_candidate/`，正式 Phase-A、旧 FinalFit、冻结 loss/model 与历史证据没有改动。新版本复用旧候选优化器、初始化、适配器和原子 checkpoint 传输，未重复实现损失、SP04 或 quantile head。

|隔离版本已经做到|正式环境还需独立许可与版本审查的具体变更|
|---|---|
|B9 九轮逻辑状态机、5228/epoch 整数覆盖、固定第9轮终点|把经核验的真实 loader 接入新的正式命名空间；真实5228更新/epoch、全验证及异常时资源许可持续检查尚未执行|
|内部人工 Batch 与元数据合约|真实文件 reader 当前不存在可执行通路。正式版本须将精确冻结ID映射、共享scaler、真实mask/SP04与同一字节流 SHA 绑定到受控数据权限；禁止把人工身份替换字符串冒充真实|
|精确 score 磁盘累计、FP64共同评价|真实10501场景的分数基数、存储占用、吞吐、配对输出归档仍待获批检查；完整效应与探索区间程序需采用最终批准的统计协议|
|本机 SQLite 四步额度、跨进程预约不可退款|正式需独立资源租约、撤销和执行事件验真；数据库本机 ACL、防篡改备份、跨主机并发与掉电持久性不能由本次单机测试替代|
|新合成 checkpoint envelope / 完整边界检查|正式 store 路径、真实artifact SHA、原始授权祖先、具体 LAST SHA 及新增恢复批准；孤立 blob/控制器提交间隙需经批准的人工对账，不自动恢复|
|Always-deny 正式接口|独立审批基础设施未存在。不能将 RejectingAuthority 改成返回 True，也不能把 JSON/commit/本任务文字作为验真服务；应单独实现并审查真实事件验证、作用域、期限与撤销|

实际优化器 campaign 只覆盖 seed2026/E0，E1/E2/其他 seed 的计划身份与固定参数来自原封闭配置；要扩大可执行 campaign 必须先有新的工程更新预算或正式执行许可。四步额度已经用尽，当前不能继续模型优化。B0 首次失败的 synthetic artifact 只做取证，未采纳为可继续训练的 LAST。

首次真实只读预检总体仍 NOT_VERIFIED：20,956 身份与67,006引用存在并不意味着全payload已验；294 payload完成、66,712待验、48真实场景限定解码、27,880场景—时相引用生成晚于分析时刻。这些为既有公开证据引用，本轮没有新增读取。历史2025路径属性访问 NOT_INSTRUMENTED 保持原样。近实时业务主张、科学协议、正式代码、未来真实preflight与首批训练分别需要独立决定。
