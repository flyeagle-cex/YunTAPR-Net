\section*{Checkpoint：关键不变式}
词法年份、目录与注册拒绝先于路径API。目录句柄、payload只读句柄绑定实际对象；读前后元数据和完整SHA相符。收据最多16 KiB，payload最多1 MiB，人工tensor最多256 KiB。仅已验证不可变字节进入
\[
\texttt{torch.load(BytesIO(verified\_bytes), weights\_only=True)}.
\]
完整模型键、AdamW矩、scheduler、CPU RNG、epoch/update、验证收据和来源通过后才安装人工字典。旧reader不用；live model/optimizer拒绝。替换、截断、错误SHA、并发写/映射、校验后替换均有负面证据。重启后无可信注册即拒绝，不采用孤立LAST。

\section*{Job：停止拥有的树}
复用原子Job后端；PID、创建FILETIME、原生executable哈希与nonce绑定实际worker。venv包装进程提前退出仍被正确处理；内存、CPU time、时间、句柄异常终止拥有的Job，不用PID-only kill。monitor直接\texttt{os.\_exit}后，内层子进程在外层清理前已退出。
