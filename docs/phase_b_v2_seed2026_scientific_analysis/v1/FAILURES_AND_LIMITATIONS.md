## 未补造的科学证据

- AUROC/AP 采用已发布精确分数并列口径的数值，未读取全像元 score 数据库重新排序。十箱不替代精确排序。
- 完整 span 分布、逐位置发生概率—极端 q32 联合关系、独立站点/雷达验证未获得，不能从最大值或汇总表重建。
- 没有新的真实推理、数据解码或 2025 读取；历史 2025 路径属性访问仍为 `NOT_INSTRUMENTED`。
- Bootstrap 是开发集日期块的探索区间；跨周相关、季节非平稳、历史选择和单 seed 限制不能由增加重采样次数消除。
- 六份最终 LAST SHA 匹配只证明本次读到的字节身份；没有反序列化验证完整恢复，也没有永久不可变存储证明。
- 备份搜索只覆盖可访问且未排除的目录和相应固定文件命名；未发现副本不等于证明不存在离线、受限、压缩或改名副本。
- GPU 驱动事件和一次极慢验证轮的根因未确立；未测长程温度、功耗或正式未来十二组稳定性。
- 资源估算是规划，不是新执行授权；没有运行 seeds2027/2028。
