## 支持到什么程度

**H-O 有一致的单 seed 开发性方向证据。** E1 保留 alpha=0.5，将 gamma 从 2 改为 0。B0/B1 的 Brier 分别降低 0.021440/0.022084。平均有雨预测从 E0 的约 0.25 降到 E1 的 0.1265/0.1220，更接近实际 0.12484。描述性十箱 ECE 从 0.1360/0.1380 降到 0.00528/0.00822；AUROC/AP 变化较小，说明概率数值与排序贡献应区分。

可靠性并非“全部已校准”：E0 在低至中概率箱高估，高概率箱低估，最高箱有空箱和极少暴露。E1 的 CP 两模型都略升，Common Core 更高；B1 的 q32>100 mm/h 暴露从 58 增到 108。因此不能概括为所有输出全面改善，或由此确定共享骨干的因果机制。

**H-Q 只在 B0 有较明确的方向证据，B1 尚不稳定。** E2 的 q32 绝对覆盖误差在 B0 改善 0.3322 个百分点，B1 改善 0.0800 个百分点但区间跨零。所有组仍低于 98.4375% 目标。B0 的 CP 略恶化，B1 略改善，覆盖改善不能独立证明分布更好。

**B1 的时序贡献限于总体指标。** 三臂中 B1 的总体 Brier、AUROC、AP、CP 点估计均较好，但 q32 欠覆盖更严重；>50 mm/h 层三臂的 B1 CP 均较高，该层只有 69 个相关暴露。E0 的 >5 mm/h 各层也均较 B0 差。不能宣称全部强度或未来年份全面优越。

## 上尾尚未解决

B1/E0、E1、E2 的最大 q32 分别约 351.08、371.51、262.93 mm/h，>100 暴露分别 58、108、57；其中参考无雨暴露分别 28、40、23。B0/E2 也出现 22 个 >100 暴露，最大约 146.51 mm/h。

这些是条件高分位数暴露，不是确定性降水预报、独立暴雨事件，也没有独立站点或雷达物理验证。已有聚合证据只保留最大 log span；完整 span 分布和逐位置发生概率—极端分位数联合分布未保存，不能补造。

## 剩余十二组最需验证

按固定 seeds2027/2028 逐组检查 H-O/H-Q 的方向与副作用能否复现，尤其是 B1 的覆盖改善是否稳定、强雨 CP 是否恶化、极端条件尾部是否随初始化显著波动。三 seed 增加初始化证据，不增加独立年份或天气事件。不得根据本结果修改矩阵或阈值。本轮没有启动新训练。
