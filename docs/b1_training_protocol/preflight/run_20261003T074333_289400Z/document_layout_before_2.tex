\section*{3. 完整共享训练协议}
Occurrence为$P(R>0.1\,\mathrm{mm/h})$，$R=0.1$为negative。focal $\alpha=0.5,\gamma=2$；32个conditional quantiles，$\tau_i=(i-0.5)/32$；$L=L_{occ}+L_{qr}$，quantile axis mean，无extra multiplier，KD=0。FP32 raw head，FP64 monotonic transform、physical quantiles和pinball，$\epsilon_{mono}=10^{-4}$。BF16 forward、FP32参数、无GradScaler、TF32=false；crossing/support/nonfinite均不得修复后继续。

AdamW：betas=(0.9,0.999)，eps=$10^{-8}$，WD=$10^{-4}$仅Conv2d kernel；bias/GN affine no-decay。amsgrad, maximize, capturable, differentiable, foreach, fused全部false。decay参数：B0-Matched 4,322,832；B1 4,325,232；两者no-decay 6,529。分组disjoint且complete，unknown参数拒绝。全局grad norm clip=5，nonfinite立即停止，记录pre/post与clip频率。

实测冻结physical batch=2，accumulation=1，drop\_last=false。每epoch 5227个batch2加1个singleton；实际loss分母6860/3430，singleton不补齐、不丢弃、不重复。每scene exactly once；两模型同一seed=2026+epoch index的独立Generator permutation。全部50个epoch计划通过。

$W=5228$，$U=261400$；max epochs=50，U是固定数学horizon，允许early stopping提前结束。one-based update $u$，LR必须在step前应用：
\[
lr(u)=\begin{cases}
10^{-4}u/W,&1\le u\le W,\\
10^{-6}+\frac{10^{-4}-10^{-6}}2\left[1+\cos\!\left(\pi\frac{u-W}{U-W}\right)\right],&W<u\le U.
\end{cases}
\]
首步$1.9127773527161438\times10^{-8}$；$u=W$精确$10^{-4}$；$u=U$精确$10^{-6}$。全部261400个数学值已验证。min\_lr下界仅用于cosine，不clamp warmup；不以validation调LR，不压缩cosine horizon。

\textbf{Validation batch=8，两模型相同。}每completed epoch完整固定顺序10501场景，无shuffle/drop/replacement。以float64全样本原始numerators累计：$val_{core}=(S_{occ}+S_{qr})/N_{valid}$，禁止batch-average。继承Brier、AUROC、exact-score-group AP、conditional pinball、32 tau coverage/error及DIAGNOSTIC\_PROXY定义。POD/FAR/CSI仍THRESHOLD\_NOT\_FROZEN。

每模型独立BEST：任何strict lower exact global core才更新，tie保留最早epoch。ES独立patience=8、min\_delta=$10^{-4}$，仅$val<best_{ES}-10^{-4}$重置计数；不可与BEST混用。其它diagnostic不能选择checkpoint。
