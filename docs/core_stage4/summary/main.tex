\textbf{执行器与预算。}复用V2双头、E0、AdamW分组、梯度裁剪与既定评价。绑定Train959、Dev963及最终共同人口SHA；两模型使用相同9轮排列和标签。每轮$\lceil959/2\rceil=480$次，各9轮共4,320次，配对硬上限\textbf{8,640次新更新}；验证每轮121批、配对共2,178批。学习率采用480步预热及24,000步原50轮轨迹前缀，第4,320步约$9.36303\times10^{-5}$，不复用5228常量。更新前先持久登记意图；失败后停止，无自动重试、恢复或额外额度。LAST与验证收据只写新实验目录。
