## 4. 校验

- 全部 28 个 run：`TP+FP+FN+TN == N_valid`、`Σbins n == N_valid`、`Σbins rain == N_rain`；
- 预期人口计数逐一通过（B0/B1 36,018,430 / 4,496,600；B2–B8 3,303,090 / 407,820）；
- B2–B8 的 16 个 run 用精确分数 sqlite 交叉验证：`P≥0.5` 计数 = `P>0.5` 计数 + 恰好 0.5 边界质量，逐 run 一致
  （边界质量合计 62,101 个有雨像元，说明 0.5 边界不能忽略；本表采用 P≥0.5 并明确标注）。

## 5. 必须随结果一起报告的限制

1. 新增分类指标是**探索性事后**指标（既有协议 `THRESHOLD_NOT_FROZEN`），不得当作预注册主指标或用于 2025 选模。
2. B0/B1 与 B2–B8 人口不同，不能合并计数或跨人口归因；主表分两组呈现。
3. 单 seed 模型（B2、B5、B6）不计算“多种子标准差”；B0/B1 的 E0/E1/E2 是损失臂不是 seed。
4. q32 覆盖普遍欠覆盖（名义 98.4375%），不能因为“某模型 q32 更高”就称其校准更好（仍低于名义）。
5. 点估计阈值分类与连续误差尚未计算；需 Tier-1 且先由研究者选定点估计规则。
