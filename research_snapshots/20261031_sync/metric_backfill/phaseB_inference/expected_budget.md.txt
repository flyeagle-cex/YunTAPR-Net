  若 H: 读取降速（外置盘休眠/接口降速），B0/B1 可能各延长 1.5–2×。

  B0/B1 同量级。**瓶颈是 ~736 GiB 的 SHA 校验读取，不是 GPU。**
- 估计误差来源（全部标注 ESTIMATE）：B0/B1 重读字节数、<PRIVATE_LOCATOR_31cc2a195c99> 当前盘速、GPU 空闲假设、目标机是否有其它 I/O。

## 6. 预算与审批边界

本预算只覆盖**推理读取与 GPU 前向**，不产生新的训练预算：
- 不训练、不写模型、不调用优化器；
- 不重跑已完成 Dev 评价（历史 JSON 只读，用于 gate 对照）；
- 不读 2025、不写入任何私有 run 目录；
- 每 run 一次遍历；gate 失败即停，不做自动重试/重放。
