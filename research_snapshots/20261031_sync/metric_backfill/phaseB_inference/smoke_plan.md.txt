## 4. 预计读取字节（B7_s2029，2 场景，来自冻结 prepared scope 的精确单文件大小）

| 类别 | 文件数（2 场景） | 精确字节 |
|---|---|---|
| 卫星 6 slot（B13/B08…，5778 文件/963 场景，均值 4,511,xxx B） | 12 | ≈ 54.1 MB |
| GFS main（963 文件 / 287,429,347 B，均值 298,473 B） | 2 | ≈ 0.60 MB |
| GFS thermo（963 文件 / 89,772,072 B，均值 93,221 B） | 2 | ≈ 0.19 MB |

| yunnan mask | 1 | 20,916 B |
| **合计（逻辑源字节）** | 18–19 | **≈ 55.7–56.5 MB** |

- B0/B1 冒烟（2 场景）：B1 为 6 帧×4.42 MB≈26.5 MB，B0 为 1 帧≈4.4 MB，加 IMERG 0.8 MB、mask 20.9 kB；
  另需读取冻结计划元数据（2024 manifest 5.35 MB + frame index CSVs 约 12.6 MB + protocol/scaler/mask 元数据），
  合计约 **45–60 MB**（B1）/ **23–35 MB**（B0）。
- 每次读取都做同 handle SHA-256 校验（B0/B1 VerifiedReader；B2–B8 SourceCache+SourceMeter）。

## 5. 预计耗时（单 checkpoint × 2 场景，GPU 空闲时）

| 阶段 | B7_s2029 等 B2–B8 | B0/B1 |
|---|---|---|
| Python/torch/冻结模块导入 + 计划构造 | 30–90 s（含 PopulationPlan 元数据哈希校验） | 60–120 s（含 16 个 frame CSV + 2 份 manifest 读取校验） |
| 模型构造 + checkpoint 加载（strict） | 5–20 s | 5–15 s |
| 2 场景读取+解码（≈56 MB，SHA） | 5–20 s | 20–60 s（B13 解码单帧约 0.5–1 s） |
| 前向 + 指标累加（1 个 batch） | 3–10 s | 3–10 s |
| **合计（每 checkpoint）** | **≈ 1–3 min** | **≈ 2–4 min** |

（2026-10-29 的 CPU `check` 实测：单 run 构造+strict load 约 15–40 s，可作为导入开销的参考。）

## 6. 期望输出与判据

输出：`outputs/_smoke/<run_id>/result.json`（不含 compact CSV；不写正式主表目录）。

必须满足（自动判据已写入 `smoke_checks`）：

1. `status == "SMOKE_COMPLETE"`；
2. `mode == "SMOKE_2_SCENES"`，`scenes_processed == 2`，`batches == 1`；
3. `new_metrics.N_valid == 2 × 3430 == 6860`（B0/B1 同为 6860；若 B0/B1 的 `valid&region` 计数不同，说明 mask 链异常）；
4. `new_metrics.N_rain > 0`（2024 Dev 两个首场景应当有雨；若为 0 记录为异常但不等于崩溃）；
5. `new_metrics.point_estimates` 含 A/B/C，`MAE/RMSE/MeanBias/Pearson_CC` 全有限；`contingency` 含
   `OCC_P` + A/B/C；每张混淆矩阵满足 `TP+FP+FN+TN == N_valid`（=6860）；
6. `candidate_D` 每阈值有 `support.N_supported + support.N_not_established == N_valid`；
7. `read_scope_actual` 存在（B2–B8 为 `meter_totals`：`opened_files` 应等于该 2 场景实际文件数 18–19，
   `delivered_bytes` 与 §4 同量级；B0/B1 为 `content_bytes_read`），且无 FAILED 状态；
8. `checkpoint_identity` 的 checkpoint/Dev 报告 SHA 与他们 registry 记录一致（默认开启 SHA 校验）；
9. `gate` 明确 `applies=false` + 原因（2 场景不复现全量 summary；B0/B1 注明 frozen evaluator 跳过）。

若任一失败：保持输出目录原样、**不要**改代码参数重试；把 `result.json` 的 `error`/`traceback` 报给 Lead，
由 Lead 决定是否允许修正后重跑。修正后重跑会重建 `_smoke/<run_id>/`（非科学产物，允许覆盖）。
