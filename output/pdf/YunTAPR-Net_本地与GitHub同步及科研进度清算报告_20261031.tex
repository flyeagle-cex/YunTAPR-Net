\section*{5. 当前科研依据与最重要的问题}
\subsection*{可支持的有限结论}
B4相对B3的三seed总体Brier、AUROC、AP和条件Pinball同向改善：平均差分别约-0.00199084、+0.00583884、+0.0184720、-0.00118203。这是同人口、配对初始化/顺序、固定E9的开发集证据；q32方向不一致，不能外推全面强雨提升。

真实DOTE相对ZERO，三seed Brier均下降，均值约-0.000892628；AUROC/AP仅1/3改善，条件Pinball2/3，q32距名义水平误差仅1/3改善。经验可靠性分解不是总体校准或地形抬升因果证明。

DTFM相对concat总体AUROC三seed同向，其余结果混合。实际B8替换额外concat融合支路，\textbf{不是B7再简单叠加一个独立模块}。单SP04训练不能替代V1.3完整多尺度目标验收。

\subsection*{极端降水结果必须保留反例}
继承10月31日专项审计：B4/B7/B8各三个seed，共九个E0/E9配置，A/B/C三种尚未冻结的点估计，在严格$R>20$ mm/h均有
\[
TP=0,\quad FP=0,\quad FN=717,\quad CSI=POD=0.
\]
无预测阳性时FAR/Precision分母为零，不能填写0。该717是同一人口的像元时次，不能乘以seed数当独立样本。$R>50$只有6个像元时次、5个窗口，独立暴雨事件数仍\path{NOT_IDENTIFIED}。

B7相对B4在(20,30]、(30,50]的条件Pinball各改善2/3；B8相对B7各仅1/3，均值退化。总体概率收益不能提升为“极端降水技能已建立”。总体q32覆盖仍低于名义98.4375%；按实际雨强条件化的覆盖率仅为描述值。

没有完整保存极端雨强×高程联合逐像元误差、事件峰值位置/时刻及独立事件目录。不能由总体误差矩重建强雨MAE/RMSE/Bias，不能把最高分位数log尺度欠幅当真实雨强峰值误差。现有最大真值约68.06 mm/h，部分严格峰值低估下界可由保存统计推出，但不是精确峰值误差或模型排名。

\subsection*{当前最重要的科研问题}
首要缺口是\key{核心创新主张与证据范围不一致}：DOTE/DTFM仍为待检验假设，尤其强雨检出、尾部覆盖、物理归因及多尺度效益尚未建立。还需区分相同Dev年的训练随机性、相依像元、时块敏感性与独立事件/独立年份泛化。不能通过选择有利指标或最好seed回避反例。
